Servicios y cortes — Administración

Crear, editar y eliminar servicios y cortes es solo para administradores: el backend pide el ID de un admin activo (X-Usuario-Id) y responde 403 si no lo eres. Las eliminaciones son bajas lógicas: el registro queda inactivo y ya no aparece en el catálogo.

Tu ID de administrador

Si hay sesión guardada se usa su ID; si no, pon aquí el ID del admin (se manda como X-Usuario-Id en cada alta, edición y baja).
